Overview

Strata is a command-line tool and Python library for creating publication-quality vector maps optimized for pen plotters. It downloads geographic data from open sources, processes it through customizable pipelines, and outputs SVG files ready for plotting.

Declarative Recipes

Define your map in YAML with sources, layers, operations, and styles. No coding required.

Smart Caching

Downloads are cached locally. Build the same map repeatedly without re-downloading gigabytes of data.

Plotter-Optimized

Multiple simplification levels, per-layer SVGs, and combined outputs designed for pen plotters.

Global Data Sources

Access data from US Census, Canada NRN/NHN, Quebec, Mexico, Natural Earth, and OpenSkiMap.

Quick Start

# Install (from the strata directory)
pip install -e .

# Create a new recipe interactively
strata new

# Or build an existing recipe
strata build examples/vermont_plotter.strata.yaml -o output

# Generate plotter fill patterns (optional)
strata plotter-fill output/vermont_plotter/svg/fine/combined.svg

# Open the result
open output/vermont_plotter/svg/fine/combined.svg

Architecture

Strata is organized into six named modules, each named after historical cartographers and scientists who embodied specific principles relevant to their function:

Mitchell - TUI Wizard

"Question everything" - Maria Mitchell's guided observation principle for interactive recipe creation

tui.app tui.screens.* tui.catalog

Thoreau - Data Acquisition

"Go to the source" - Downloads and caches geographic data from authoritative sources

thoreau.census thoreau.quebec thoreau.canada thoreau.mexico thoreau.naturalearth thoreau.openskimap thoreau.cache

Maury - Pipeline Orchestration

"Coordinate many sources" - Parses recipes and orchestrates the build process

maury.recipe maury.pipeline

Humboldt - Geometry Processing

"Unity in diversity of phenomena" - Spatial transformations and analysis

humboldt.geometry humboldt.projection

Kelley - Output Generation

"Maps are evidence, not decoration" - Renders final outputs for comprehension

kelley.svg kelley.plotter_fill

CLI Reference

Strata provides a comprehensive command-line interface for all operations.

Main Commands

Command Description Status
strata new Launch interactive TUI wizard to create a new recipe Working
strata build Build outputs from a recipe file Working
strata prepare Download and cache all sources without building Working
strata validate Check a recipe for errors Basic
strata preview Preview data within bounds (feature counts, quick SVG) Working
strata cache Manage local data cache Working
strata plotter-fill Convert SVG fills to hatch patterns New

strata build

strata build [OPTIONS] RECIPE

Options:
  -f, --format TEXT   Only build specific format (svg, geojson, pmtiles)
  -q, --quality TEXT  Only build specific quality level
  -l, --layer TEXT    Only build specific layer(s)
  -o, --output PATH   Output directory
  --no-cache          Don't use cached source data
  --dry-run           Show what would be built
  -v, --verbose       Show detailed progress

Examples

# Build everything
strata build examples/vermont_plotter.strata.yaml -o output

# Build only SVG at fine quality
strata build recipe.yaml -f svg -q fine -o output

# Build only the water layer
strata build recipe.yaml -l vt_water -o output

# Dry run to see what would happen
strata build recipe.yaml --dry-run

strata plotter-fill New

strata plotter-fill [OPTIONS] SVG_FILE
strata plotter-fill-all [OPTIONS] DIRECTORY

Options:
  --spacing FLOAT     Base line spacing (default: 3.0)
  --stroke-width FLOAT  Output stroke width (default: 0.5)
  --no-outlines       Don't include polygon outlines
  --output PATH       Output file path

Examples

# Convert a single SVG
strata plotter-fill combined.svg

# Convert all combined.svg files in output directory
strata plotter-fill-all output/

# With custom settings
strata plotter-fill combined.svg --spacing 4.0 --stroke-width 0.3

strata cache

# Show cache location
strata cache path

# List cached data
strata cache list

# Clear all cached data
strata cache clear

Recipe Format

Recipes are YAML files that define everything needed to build a map.

Basic Structure

name: my_map
description: A description of this map
version: 1

sources:
  # Define where data comes from
  source_name:
    uri: census:tiger/2023/vt/cousub
    description: Vermont towns

layers:
  # Define how data is processed and styled
  - name: layer_name
    source: source_name
    operations:
      - type: simplify
        tolerance: 0.0003
    style:
      stroke: "#424242"
      stroke_width: 0.5
      fill: "#f5f5f5"
    order: 1

output:
  bounds: [-73.44, 42.72, -71.46, 45.02]
  projection: epsg:4326
  formats:
    - type: svg
      quality:
        - name: fine
          simplify: 0.0002
      options:
        combined: true
        plotter_fill:  # Optional: auto-generate hatch patterns
          enabled: true
          spacing: 3.0

Multiple Sources per Layer

layers:
  - name: lake_champlain
    source: [champlain_vt, champlain_ny]  # Merge two sources
    operations:
      - type: merge
      - type: simplify

Style Options

OptionTypeDescription
strokeColorLine/border color (hex)
stroke_widthNumberLine width in points
fillColorFill color (hex or "none")
fill_opacityNumberFill opacity (0-1)
fill_byStringColor by attribute column
color_mapObjectAttribute-to-color mapping
vary_fillBooleanSlight color variation per feature
dash_arrayStringDashed line pattern (e.g., "5,3")

Plotter Fill Options New

output:
  formats:
    - type: svg
      options:
        combined: true
        plotter_fill:
          enabled: true          # Enable plotter fill
          spacing: 3.0           # Base line spacing
          stroke_width: 0.5     # Output stroke width
          include_outlines: true # Include polygon outlines

When enabled, creates combined_plotter.svg with colored fills converted to unique hatch patterns.

Operations

Operations transform geometry data in the processing pipeline.

simplify

Reduce geometry complexity using Douglas-Peucker algorithm.

- type: simplify
  tolerance: 0.0003  # In degrees (for WGS84)
  preserve_topology: true

subtract

Cut away geometry from another layer (e.g., water cutouts from towns).

- type: subtract
  target: vt_water  # Source name to subtract

# Or subtract multiple sources
- type: subtract
  target: [vt_water, quebec_hydro]

merge

Merge all features into a single geometry.

- type: merge

merge_touching

Merge features whose geometries touch or overlap. Essential for cross-border features like Lake Memphremagog.

- type: merge_touching
  buffer_distance: 0.0001  # ~10m tolerance for near-touching

dissolve

Merge features by attribute value (e.g., merge lake polygons by HYDROID).

- type: dissolve
  by: HYDROID

clip

Clip to a boundary or the output bounds.

- type: clip
  target: bounds

buffer

Expand or shrink geometries.

- type: buffer
  distance: 0.001  # Positive = expand, negative = shrink

clean

Fix topology issues and remove slivers.

- type: clean
  buffer_distance: 0.0001

remove_holes

Fill interior rings (holes) in polygons.

- type: remove_holes
  min_hole_area: 0.0

extract_islands

Extract holes as separate features (for drawing islands).

- type: extract_islands
  min_area: 0.0001

Plotter Fill New

Convert colored SVG polygon fills into hatched line patterns for single-pen plotter output.

How It Works

  1. Extracts unique fill colors from SVG
  2. Maps each color to a unique pattern/angle combination
  3. Darker colors get denser fills (smaller spacing)
  4. Uses rat-king CLI for fast pattern generation
  5. Outputs line-only SVG suitable for single-pen plotting

Available Patterns

29 pattern types: lines, diagonal, crosshatch, zigzag, honeycomb, brick, herringbone, grid, wiggle, spiral, concentric, radial, scribble, hilbert, and more.

YAML Integration

output:
  formats:
    - type: svg
      options:
        combined: true
        plotter_fill:
          enabled: true
          spacing: 3.0         # Line spacing (smaller = denser)
          stroke_width: 0.5    # Output line width
          include_outlines: true

CLI Usage

# Convert a single SVG
strata plotter-fill combined.svg

# Convert with custom settings
strata plotter-fill combined.svg --spacing 4.0 --stroke-width 0.3

# Batch convert all combined.svg files
strata plotter-fill-all output/

Cross-Border Lake Example

Demonstrating merge_touching for Lake Memphremagog (VT/Quebec):

sources:
  vt_water:
    uri: census:tiger/2023/vt/areawater
  quebec_hydro:
    uri: canada:canvec/hydro

layers:
  - name: lake_memphremagog
    source: [vt_water, quebec_hydro]
    filter:
      min_area_km2: 10
    operations:
      - type: merge_touching
        buffer_distance: 0.001
      - type: clean
      - type: simplify
        tolerance: 0.0003
    style:
      fill: "#1565c0"
