## Module Naming Reference

| Person | Module | Contribution |
|--------|--------|--------------|
| William Smith | `strata` (core) | "Father of English Geology" - layer ordering and superposition |
| Henry David Thoreau | `strata.thoreau` | Naturalist observation - data acquisition from authoritative sources |
| Alexander von Humboldt | `strata.humboldt` | Scientific synthesis - processing and transformation |
| Matthew Fontaine Maury | `strata.maury` | "Pathfinder of the Seas" - pipeline orchestration |
| Florence Kelley | `strata.kelley` | Social cartography - visualization and output |
